# Лабораторна №9: SimpleDAO + MockProtocol
Автор: Вертій Максим Олександрович

Запуск (потрібен Node.js 22):
```
npm install
npm run lab
```
Вузол окремо запускати не треба. У кінці виводу рядок `fee після виконання пропозиції: 10`.
Контракти: contracts/SimpleDAO.sol, MockProtocol.sol, AssetToken.sol (VertiiCoin).
